# Fastlane listing images

Place store artwork here before the fdroiddata merge request.

| File | Recommended size |
| --- | --- |
| `icon.png` | 512 × 512 PNG (no alpha preferred for F-Droid) |
| `featureGraphic.png` | 1024 × 500 PNG |
| `phoneScreenshots/*.png` | at least 320 px on the short side; typical 1080 × 1920 |

`icon.png` currently copies the launcher mipmap as a stand-in. Replace it with a 512×512 master icon and add 2–8 phone screenshots before submission.

Do not commit screenshots that show copyrighted album art if that would violate F-Droid’s metadata policy; prefer the in-app chrome and public-domain / freely licensed artwork.
